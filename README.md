# Personal Apps Shortcuts

Private per-user shortcuts that appear at the top of the Odoo apps menu (Community) or Home Menu (Enterprise), with custom icons, drag & drop reordering, and support for external/internal URLs.

## Features
- Per-user private shortcuts (only visible to the owner)
- Appears above a divider in CE apps dropdown, and as tiles in EE Home Menu
- Add via "+" tile or user menu (depending on minimal mode)
- Drag & drop reordering
- Custom icon upload (Image)
- Opens in same tab or new tab
- URL validation with scheme allowlist (http, https, relative)
- Minimal mode to hide UI chrome
- Works on Odoo 17 CE & EE

## Installation
1. Copy to your addons path
2. Update apps list
3. Install `personal_apps_shortcuts`
