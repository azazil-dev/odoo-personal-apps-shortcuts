Private by Design

Every user sees only their own shortcuts. Record-level rules enforce isolation — even administrators cannot see other users' shortcuts.

Custom Icons

Upload any PNG, JPG, SVG, or WEBP icon (max 1 MB, auto-resized to 128×128). No icon? A colorful initial tile is generated automatically.

Drag & Drop Reorder

Drag tiles to reorder them on desktop. Order is saved immediately and persists across reloads and re-logins.

Mobile Ready

Long-press a tile to enter edit mode on touch devices. Edit and delete buttons meet the 44 px minimum tap-target size.

Internal & External URLs

Link to any https:// URL or internal Odoo path like /web#action=…. Dangerous schemes (javascript:, data:) are blocked server-side.

Zero Configuration

Install and go — no admin setup required. Each user manages their own shortcuts from the apps menu itself.

How It Works

1
Click "＋ Add"

The + Add tile is the last item in the shortcut section. Click it to open the add dialog.

2
Fill & Save

Enter a name, URL, and optional icon. Click Save — the tile appears instantly without a page reload.

3
Hover to Edit

Hover any shortcut tile to reveal the ✏ edit and 🗑 delete buttons. On touch devices, long-press to enter edit mode.

4
Drag to Reorder

On desktop, drag tiles to your preferred order. The new sequence is saved automatically.

Security & Privacy

  • Record rule: [('user_id', '=', user.id)] — all CRUD ops
  • Administrators are not exempted from the record rule
  • Controllers re-check ownership — client IDs are never trusted
  • user_id always forced to current user on create; not writable after
  • URL validation server-side: blocks javascript:, data:, vbscript:
  • External links use rel="noopener noreferrer"
  • Icon uploads: MIME check, 1 MB limit, resized to 128×128
  • User deletion cascades to their shortcuts

Requirements

  • Odoo 17.0 Community or Enterprise (on-premise or Odoo.sh)
  • Depends only on web — no extra Python packages required
  • Single module for both editions; Enterprise patch is lazy-loaded at runtime
  • Up to 40 shortcuts per user (configurable via system parameter)
