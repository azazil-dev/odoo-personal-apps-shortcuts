Key Features

Standalone Fullscreen Launcher

Replaces the standard narrow dropdown with an elegant, responsive fullscreen app grid. Completely standalone — zero external addon dependencies!

1-Click App Picker (+)

Click the + Add tile to open an instant modal showing all installed Odoo apps. Pick any app to create a shortcut immediately with its original icon and internal action URL.

Smooth Drag & Drop Reordering

Rearrange shortcut order effortlessly using native HTML5 drag-and-drop. Sequences update optimistically on screen and persist immediately to the database.

Real-Time Reactive UI

Built with Owl 2 reactive states: adding, editing, or deleting a shortcut reflects instantly in real time without refreshing or reloading the browser page.

Instant Live Search

Search through all installed applications and shortcuts with keyboard hotkey H and press Enter to launch immediately. Close anytime with Esc.

Private & Secure by Design

Strict record rules ensure users only see and manage their own shortcuts. URLs are verified against dangerous schemes (javascript:, data:).

How It Works

1. Open Launcher

Click the app grid icon in the top navbar or simply press H anywhere in Odoo.

2. Add Installed App

Click the + Add tile. Click any installed app in the picker dialog for instant 1-click shortcut creation.

3. Organize & Reorder

Drag and drop tiles to rearrange their sequence, or toggle edit mode to customize custom labels or delete shortcuts.

Technical Specifications

Parameter Specification
Compatibility Odoo 17.0 Community Edition (CE)
Module Dependencies web (No external modules required)
Frontend Architecture OWL 2 (Component, useState, useBus, useHotkey) + SCSS Responsive Grid
Data Isolation Strict multi-user record rule: [('user_id', '=', user.id)]
Internal Navigation Direct action dispatching via actionService.doAction() and menuService.selectMenu()
