Personal Apps Shortcuts

Odoo 17, 18, 19 CE & EE Private by Design Drag & Drop OPL-1  ·  Free

Let every Odoo user build a private set of shortcuts — to external sites or internal Odoo pages — that appears at the top of the apps menu, with custom icons, drag-and-drop reordering, and native look and feel on both Community and Enterprise.

Interactive personal shortcut bar with drag & drop, custom icons, and seamless integration right inside the Odoo apps menu.

Key Features

Strict Privacy & Data Isolation

Strict record rules ensure users only see and manage their own shortcuts. Administrators are NOT exempted.

HTML5 Drag & Drop Reordering

Rearrange shortcuts effortlessly with optimistic UI updates and instant server persistence.

Internal & External Destinations

Link to external URLs (Google Docs, Jira, Portal) or internal Odoo actions/views with custom icon uploads.

Enterprise & Community Ready

Works seamlessly on Community dropdown and Enterprise Home Menu fullscreen grid without extra dependencies.

Where It Appears

Community — Apps Dropdown
Top navbar → Apps menu (dropdown)

Shortcut entries appear above a divider line, using the same icon + label style as native CE app entries.

Enterprise — Home Menu
Full-screen Home Menu (app grid)

Shortcut tiles match the exact width, gap, and column count of the native EE app grid — seamlessly integrated.
